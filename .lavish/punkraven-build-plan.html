The job

What the site has to do

Make a skeptical technical reader believe this infrastructure company is real and serious — without letting them conclude that anything has shipped, or that this is a legal services business.

Typefaces Decided

Orbitron stays as the display face only. A readable body face carries prose, Fira Code carries data, and Noto Sans per script is wired for the nine-script block.

Orbitron ships subsets:["latin"] — it cannot render any of the nine Indic scripts, and lacks §, ₹ and →, which appear in the copy.

Used where a node graph genuinely illustrates content — the T&T speech pipeline, the two-tier stack, Lawman's retrieval flow — not in every section.

Hardened first: cn ported off the non-existent @workspace/ui path, prefers-reduced-motion guard rendering static traces, dynamic import, aria-hidden.

Dark mode Decided

The next-themes toggle is removed. The site alternates fixed light and dark bands by design, per §5.1.

Knock-on: primitives.ts title() carries dark: gradient variants needing rework once the toggle is gone.

Design system · §5

The amber rule is the signature

--signal amber is reserved exclusively for uncertainty, status and unverified claims. Never a heading, never a hover state, never a CTA. The single warm colour on an otherwise cool site always means we are not certain about this.

Every amber mark in this document obeys that rule. The token will be named uncertain, never amber or warning, so decorative use reads as wrong at the call site.

TokenValueRole
--ink#0F131BRaven black, blue-shifted
--ink-soft#39404ESecondary text
--paper#F3F5F8Cool paper, deliberately not cream
--sheen#5B4FCFViolet. Links, CTA, focus rings
--sheen-alt#17968FTeal. Diagram strokes, stack connector

The nine-script hero cannot be machine-built Awaiting copy

§5.5 calls this the site's one deliberate risk — it demonstrates the 22-language claim instead of asserting it. The translations do not exist in any source document. A sweep of U+0900–U+0DFF across all four files returns zero matches: they are 100% Latin script. No translation table, no transliteration, no sample strings.

Machine-translating them unverified is the highest-risk shortcut available here. §5.5 requires native-reader verification per script and warns that a mangled script on a page about language coverage is a self-inflicted wound. The strings must come from a human — and will be supplied. The section is scaffolded in Phase 4 and filled on delivery.

Useful finding: the nine scripts map exactly onto A4's Tier A list (Devanagari covers Hindi and Marathi, giving nine scripts for ten languages). The block restates Tier A specifically, not all 22 — worth preserving in its caption and aria-label.

Eight defects in the source documents

Errors in the copy docs themselves, not the spec. Each is handled in the phase plan; none is silently resolved.

§3.2 and §2b.5 contradict

§3.2 mandates T&T Variant B for the homepage. Its proof line carries a latency figure and a cost figure — both barred from / by §2b.5.

§2b is a hard rule, so it wins: the proof line is de-numbered. The homepage T&T block keeps only 22 scheduled languages and MIT-licensed.

A wrong claim would go site-wide

Variant C reads “all 22 Indian languages”, dropping scheduled. §3.2 puts Variant C in the footer and nav flyout — every page.

The A0 page title has the same defect. Both corrected to “22 scheduled Indian languages”; the doc enforces this rule against itself elsewhere.

Deleting §0 does not remove NyayaSetu

Four occurrences. Two sit inside excluded §0 — two do not: the metadata line at the top of the file, and the closing italic “We build it as NyayaSetu.”

A naive section-delete passes the grep and still leaks. The top line is exactly what gets pasted into a meta description by accident.

Competitor names survive the §7 cut

§3.4 excludes §7. But §6 is included and names GPT-4, Llama 2, PaLM 2, Lexis+ AI and Westlaw with fabrication rates. §4 says the app is “as familiar as Claude or ChatGPT”.

Naming Lexis and Westlaw with a failure percentage is a disparagement exposure. Keep the principle, drop the product names and percentages.

Part D points at the wrong section

Part D says T&T's non-legal buyers are named in “B5 and C5”. They appear only in C5.

So / currently names zero non-legal buyers — and that is where the cold-read test is hardest. The T&T homepage block must supply them.

Lawman's CTA violates the spec

Lawman's closing CTA reads Get early access. §2b.7 permits only “Request early access”.

Spec wins on structure, copy wins on wording — this is structural. The button reads “Request early access”; the India phrasing becomes supporting text.

Missing page metadata

lawman-summary.md has no metadata table at all. C0 has metadata but no OG fields, where B0 does.

§7 requires metadata plus OG tags from each doc's table. Two pages cannot satisfy that as written; values must be authored.

“Advice” hides in an included section

LawSafe §2 cites Tele-Law's “1 crore pre-litigation advice sessions” — a government programme's figure that reads as LawSafe's own offering.

Also in the TL;DR: “Available in all local Indian languages”, an unbounded unsourced claim. Neither is on the include list; both stay out.

Confirmed clean: no social proof of any kind in any document — anything of that sort on the site would be fabricated. No “22+” phrasing. All uses of “advice” in the company and Lawman docs are disclaimers, so Phase 5's gate is satisfiable as written. lawman-summary.md contains zero numeric figures in body copy, deliberately — do not add any. LawSafe's §4 scope list runs to 49 practice areas in one sentence; all six of the spec's prescribed replacements are source-backed.

Risks

What could still go wrong

Lighthouse 95+ with HeroUI v3 beta

A beta component library plus framer-motion on a site that must score 95+ across all four categories. The circuit board is dynamically imported to mitigate; if the budget still fails, it is the first thing cut.

The cold-read test needs a human

It requires a reader who has not seen the source documents. I cannot run it on myself. Needed at the end of Phase 2, and it can fail the phase regardless of what else passes.

Copy apparatus leaking

The docs contain attribution lines, field labels, variant blocks and claim tables that must never reach a page. Mitigation: hand-transcribe into typed content entries, never pipe markdown to HTML.

Prose measure vs the scaffold

The spec wants 68ch; DefaultLayout currently gives 1232px, roughly 106 characters per line. Reconciled in Phase 1, but it touches every page.
